# Irving College Baptist Church TV — Support

Email **icbcnextsteps@gmail.com** for help with the LG webOS TV app. Include the TV model, webOS version, app version, what you selected and any error message. Do not send passwords or sensitive personal information.

- Use **Watch Live** during a church broadcast. Livestreaming is not advertised as a 24-hour channel.
- Use **Browse Sermons** to select an archive.
- **Refresh** reloads the library. **Retry** reconnects the selected video.
- Archived videos support ±30-second seeking; live seeking is disabled.
- **Back** leaves playback or returns from Privacy & Support. Home-level Back uses an exit confirmation in this build.
- Check your TV's Internet connection if content cannot load.

Website: https://www.irvingcollege.church/
