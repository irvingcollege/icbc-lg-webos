LG webOS development build for Irving College Baptist Church.

- Preserves the Samsung app's design, artwork, sermon catalog logic and streaming URLs.
- Uses HTML5 video with native HLS preference, bundled HLS fallback and LG remote controls.
- All 29 local automated tests passed. Built using official @webos-tools/cli 3.2.6 and verified against the staged application files.

**Physical LG TV compatibility has not been verified.** Production catalog CORS requires validation before release. See docs/verification.md and docs/install-and-submit.md in the source archive or repository.

Download the .ipk for Developer Mode installation, or the source ZIP for development. SHA256SUMS.txt verifies both files. This is a prerelease development package, not an LG-certified Content Store release.
