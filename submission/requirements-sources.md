# Official requirements reviewed

Reviewed October 19, 2026 using LG's public developer documentation. Seller Lounge's signed-in form, its current field limits and the official QA templates still need to be checked in the church's account.

- [Approval process](https://webostv.developer.lge.com/distribute/app-approval-process): prepare an IPK, images, a UX scenario and the official self-checklist with actual results.
- [Self-checklist](https://webostv.developer.lge.com/distribute/app-self-checklist): includes remote navigation, pointer interaction, selection states, content and privacy checks. Its official downloadable QA documents are at https://webostv.developer.lge.com/assets/checklist/documents_for_app_qa.zip .
- [App resources](https://webostv.developer.lge.com/develop/getting-started/app-resources): 80/130-pixel packaged icons, separate 400-pixel store icon, branded 1920x1080 splash and launcher-title guidance.
- [Metadata](https://webostv.developer.lge.com/develop/references/appinfo-json): identifiers, versions, resource references, description and permissions.
- [Icon design](https://webostv.developer.lge.com/develop/guides/icon): flat, recognizable artwork and internal padding.
- [Back handling](https://webostv.developer.lge.com/develop/guides/back-button): general custom exit dialog/window.close guidance; read alongside the newer model-specific self-checklist wording. The apparent webOS23–25 difference remains a release gate.
- [Privacy](https://webostv.developer.lge.com/develop/guides/privacy-guideline): describe actual data processing and included libraries; policy supplied in-app and as a public GitHub page.
- [Seller Lounge](https://seller.lgappstv.com/): church account controls seller details, category options, ratings, target groups, portal assets/templates and final submission.

The web research tool could read the public pages but could not materialize LG's binary QA template ZIP. The source workspace's HTTP policy blocks direct access to LG's website.
